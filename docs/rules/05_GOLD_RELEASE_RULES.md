# GOLD ve yayın kuralları

Bir soru ancak aşağıdakilerin tümü sağlanırsa GOLD olabilir:
- Doğruluk doğrulaması PASS
- Tek doğru cevap PASS
- Yaş ve kazanım uygunluğu PASS
- 3. sınıf ve sonrası zorluk kapısı PASS
- Seçenek kalite puanı >= 90
- Çeldirici gerçekçilik puanı >= 90
- Bütün seçenekleri okuma zorunluluğu PASS
- Semantik tekrar kontrolü PASS
- Açıklama öğreticiliği >= 85
- İnsan gözü puanı >= 90

Bir aile ancak:
- En az 4 gerçek iskelet
- En az 3 farklı düşünme yolu
- En az 3 farklı çeldirici planı
- 60 oturum kapasite testinde semantik çakışma 0
koşullarıyla GOLD aile olabilir.
