# Belge Dizini

Eski faz raporları, patch notları, Cursor promptları ve tarihsel kabul belgeleri `md/arsiv/` klasöründedir.

Bu belgeler güncel ürün kararı değildir. Güncel durum için uygulamadaki **Soru Motoru Komuta Merkezi** esas alınır.

- `raporlar/`: Aşama raporları.
- `kurallar/`: Geliştirme ajanı ve kalite politikası belgeleri.
- `arsiv/`: Eski kök Markdown belgeleri.
